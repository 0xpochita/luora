# Alchemy "Web3 security tools" list vs Luora (2026-10-10)

## What this is

Every tool on Alchemy's dapp-store list
[Web3 security tools](https://www.alchemy.com/dapps/top/security-tools?page=1), compared with
Luora. On 2026-10-10 the list had **217 entries on 9 pages** (25 per page, 17 on page 9). Each
tool's own website, docs or GitHub README was opened and summarised in one sentence; the Alchemy
blurb was used only to find the link.

Luora, for reference: a local tool that turns a Foundry run (`forge test -vvvv`) into a readable
call trace, a contract graph, a Scenario lab that writes Foundry tests of intended behaviour,
Slither / Aderyn findings, `forge coverage` and an Ask AI panel on the auditor's own key.

**Score** (similarity to Luora)

- **3**: overlaps the trace viewer, contract graph, test-scenario writing or auditor code-review workflow directly
- **2**: an auditor-side analysis tool Luora could integrate, or a firm shipping one
- **1**: same security space, different user or job (most audit firms, bounty platforms, monitoring, CTFs)
- **0**: unrelated (end-user wallet protection, AML, scam-token scanners, generic infra)

Result: 9 tools score 3, 51 score 2, 106 score 1 and 51 score 0. 10 entries could not be checked
first-hand and are marked **UNVERIFIED** in the table.

### Notes on the list itself

- By category: 85 audit firms, 64 other (AML, education, infra, formal verification, testing), 17 static analysis, 15 monitoring, 14 wallet security, 11 fuzzing, 7 bounty platforms, 2 tx debuggers, 2 explorers. Auditor-side
  *tooling* is a small part of the list.
- **No tool on the list combines a test-run trace, a contract graph and test writing in one
  local app.** The closest are split across Phalcon (trace), VSCode Solidity Auditor / Wake
  (graphs in the editor) and the fuzzing frameworks (tests).
- Tenderly, Foundry's own `forge debug`, Slither and Aderyn are **not on the list**. Slither and
  Aderyn appear only through their makers, Trail of Bits and Cyfrin.
- Some listings are stale or have nothing to do with security: OpenZeppelin Defender is closing
  (2026-07-01), Wallet Guard closed (2025-03-31), the ERC-20 Verifier site is gone, Manticore,
  Octopus and Etheno are archived, and Mosaia, Solve3, GuardiaNNN.AI and Feed Protocol are not
  security tools. ZIION is listed twice.

## Score 2 by theme: what is adjacent and could plug in

- **Static analysers and scanners** (Mythril, Semgrep Smart Contracts, SolidityScan, MetaTrust
  MetaScan, Glider, Sec3 X-ray, Octopus, EVMole, Solidity Shield, Almanax, Octane, AgentLISA,
  Auditr, DeFi Watchdog, ERC-20 Verifier, QuillShield skills). *Learn:* Luora's findings import
  takes Slither / Aderyn today. Mythril, Semgrep (SARIF) and Pessimistic's **Slitherin** detectors
  are the open, local ones that fit the same "findings next to the graph" panel. The hosted AI
  scanners are a different model: code leaves the machine, while Luora's Ask AI uses the auditor's
  own key locally. *Differs:* none of them show a trace or tie a finding to a run.
- **Formal verification / symbolic execution** (Certora Prover, Runtime Verification Kontrol and
  Simbolik, solc-verify, Manticore, Beosin, CertiK). *Learn:* Kontrol runs on Foundry tests, so a
  Luora scenario could be handed to it as a proof target. Simbolik is a step debugger for Solidity
  in VS Code, a close cousin of the trace view. *Differs:* proof tools need a spec language;
  Luora stays with plain Foundry tests.
- **Fuzzers on other chains or stacks** (Tayt for Cairo, Trident for Solana, Scribble, Etheno).
  Same idea as Echidna, outside Luora's Foundry/EVM scope.
- **Audit firms that ship auditor tooling**: Trail of Bits (Slither, Echidna, Medusa), Cyfrin
  (Aderyn, Solodit), Consensys Diligence (Mythril, Scribble, Diligence Fuzzing), Ackee (Wake,
  Trident), Perimeter (fuzzlib, Arachne), Pessimistic (Slitherin), Dedaub (decompiler + detectors),
  Veridise (Vanguard, OrCa, AuditHub), Verichains (Revela decompiler), Enigma Dark (invariant
  suites), Oak Security (pre-audit agent), Nethermind, Null Return, Audita, Cyberscope, ScaleBit,
  Accretion, Adevar Labs, SecureDApp, BlockSec. *Learn:* the firms' public tools set what auditors
  expect to import. Supporting Solodit links on findings (Cyfrin) and Medusa output would cover
  most of them. **CLAWDIT** ships a Claude Code plugin that pairs AI agents with Slither + Aderyn
  and Solodit search, the closest in spirit to Luora's Ask AI + findings, but without a trace or
  graph.
- **Audit platforms**: **Cantina** (Apex agentic code review + bounties). Same users, hosted.
- **Other**: **Anvil** (the local node under every `forge test`; Luora's natural source for
  fork-mode runs), **codeslaw** (search verified source across chains by pattern; a "find similar
  code" link from a graph node would be useful), **Robot Framework Solidity Toolkit** (test
  automation around Foundry/Hardhat with static analysis).
